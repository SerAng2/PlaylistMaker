# PlayList-Maker: мобильное приложение для поиска музыкальных треков


Нативный Android‑клиент для поиска музыки, управления аудиоконтентом. 
Приложение позволяет находить треки по названию, создавать плейлисты и прослушивать музыку с удобным интерфейсом.

## Стек технологий:
* **Язык программирования:** Kotlin
* **UI‑фреймворк:** XML
* **Архитектура:** MVVM
* **Сетевые запросы:** Retrofit, OkHttp
* **Локальная БД:** Room
* **Внедрение зависимостей:** Koin
* **Асинхронность:** Coroutines / Flow
* **Инструменты:** Android Studio, Git, GitHub, Gradle

## Функционал приложения:
* поиск музыкальных треков по названию
* добавление треков в «Избранное» для быстрого доступа
* создание и редактирование пользовательских плейлистов
* воспроизведение аудио (пауза, переключение треков)
* отображение информации о треке (название, исполнитель, альбом, длительность, обложка)
* кэширование обложек альбомов для офлайн‑просмотра

## Выводы по результатам проекта:

* Реализована стабильная интеграция с внешним API, обеспечивающая быстрый поиск и получение метаданных о треках.
